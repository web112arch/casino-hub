# 🎮 ArcadeHub

ArcadeHub is a modern **crypto / web3 arcade hub** built with React and Tailwind CSS.

The project is designed as a modular platform to host casual and casino-style games, with future support for blockchain integrations such as wallets, on-chain scores, and token-based mechanics.

---

## ✨ Features

- Modular game hub architecture
- Modern crypto-style UI (dark / neon)
- Ready for Web3 integrations
- Responsive layout (desktop & mobile)
- Authentication-ready structure

---

## 🧱 Tech Stack

- React
- Tailwind CSS
- JavaScript
- Web3-ready architecture
